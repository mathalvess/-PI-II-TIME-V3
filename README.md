## Como rodar o backend

Requisito: Node.js na versão LTS (confira com `node -v`).

```
cd backend
npm install
npm run dev
```

Depois acesse no navegador:
- http://localhost:3000 (mensagem de servidor funcionando)
- http://localhost:3000/health (resposta `{"status":"ok"}`)
